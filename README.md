# Мій іспит — український тренажер для усної атестації

69 питань із фінального українського документа. Для кожного питання вручну складені опорна схема і коротка відповідь для усного іспиту. Повний вихідний текст відповіді доступний для звірки.

## Як опублікувати безкоштовно

1. Створіть публічний репозиторій GitHub (якщо матеріали дозволено публікувати).
2. Завантажте до кореня репозиторію `app.py`, `questions.json`, `requirements.txt`.
3. Відкрийте https://share.streamlit.io/ і створіть застосунок із цього репозиторію, головний файл — `app.py`.
4. Відкрийте отримане посилання на телефоні.

**Увага щодо конфіденційності:** питання та відповіді містять корпоративні процеси й назви Bunge. Перед публікацією у відкритому репозиторії отримайте дозвіл компанії або використовуйте лише дозволені матеріали. Streamlit Community Cloud може вимагати публічний GitHub-репозиторій; якщо публікувати не можна, не завантажуйте корпоративні тексти у відкритий доступ.

## Режими

- **Навчання:** 7 днів по 10 питань (останній день — 9), із повторенням складних із попередніх днів.
- **Повторення:** проблемні, уже пройдені або всі питання.
- **Білет:** 5 випадкових питань для усного іспиту.
- **Довідник:** пошук і повні відповіді.

Спочатку людина відповідає без підказки, потім за ланцюжком ключових слів, а далі звіряється зі стислим або повним варіантом.

## Прогрес

Результати зберігаються **у URL**, а не автоматично в пам’яті телефону. Зберігайте оновлену адресу після занять. Є експорт/імпорт резервної копії прогресу у JSON. Якщо прогрес важливий, користуйтеся резервною копією. Це обмеження безсерверного безкоштовного прототипу.

## Застереження щодо джерела

- Питання **44** не має відповіді в оригінальному документі. Перелік ПНВ слід отримати від служби охорони праці Bunge.
- Нормативні строки, суми, посилання на органи й корпоративні процедури взяті з наданого документа, **не перевірені на актуальність**.
- У документі є різні пороги кисню для суміжних ситуацій (19,5% і 20%); їх слід уточнити за чинною процедурою підприємства.
- Для першої допомоги та ліквідації розливів керуйтеся актуальними паспортами безпеки речовин, процедурами підприємства і вказівками екстрених служб. Не нейтралізуйте хімічні опіки кислотами чи лугами на шкірі.

pip install -r requirements.txt
